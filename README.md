# 『あの案件どうなった？』試作アプリ

## 開き方

`index.html` をダブルクリックするだけでも使えます。

ホーム画面への追加や、通信がない状態での再表示まで確認する場合は、`start.cmd` をダブルクリックします。

黒い画面を閉じると、試作アプリも止まります。保存した案件や写真は、同じブラウザの端末内に残ります。

PowerShellから開く場合は、このフォルダーで次を実行します。

```powershell
node server.mjs
```

表示された `http://localhost:4173` をブラウザで開きます。

## 保存について

- 案件・メモ・写真は、利用したブラウザの端末内だけに保存されます。
- 機種変更やブラウザのデータ削除に備え、画面下部の「データを保存」を定期的に使ってください。
- 別のブラウザで開いた場合、元のブラウザのデータは自動では表示されません。

## ファイルの役割

| ファイル | 役割 |
|---|---|
| `index.html` | 1ページの画面 |
| `styles.css` | 見た目とスマホ表示 |
| `app.js` | 入力・削除・検索・保存操作 |
| `storage.js` | 端末内保存・写真の縮小 |
| `links.js` | 同じ案件と共通語を見つける |
| `view.js` | 最新状況とつながりの表示 |
| `manifest.webmanifest` | ホーム画面追加の情報 |
| `sw.js` | 一度開いた後の再表示 |
| `server.mjs` | 手元で試すための起動補助 |
